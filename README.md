# Cat Sanctuary

Cat Sanctuary is a cat personality quiz made with HTML, CSS, and JavaScript. The idea is to answer a few questions and find out which cat matches your personality.

## Built With

- HTML
- CSS
- JavaScript

## How to Run

Download the repository and open `index.html` in your browser.

## What I Learned

I practiced using JavaScript to make the page interactive and CSS to build the design.
